## Short Description (max 132 characters)


## Detailed Description

```
LovableGrab lets you export the complete source code of your Lovable.dev projects instantly.

HOW IT WORKS
1. Open any project on lovable.dev
2. Click the LovableGrab icon in your toolbar
3. Hit "Export Project" — your code downloads as a ZIP

FEATURES
• One-click export — no terminal, no CLI tools
• Automatic authentication — uses your existing Lovable session
• Full project download — all files, all folders, one ZIP
• Works with both direct login and 3rd-party auth (Google, GitHub)
• In-page download button in the Lovable sidebar
• Dark-themed popup with project info at a glance
• Privacy-first — no data collection, no analytics, no tracking

WHEN TO USE IT
• Back up your Lovable projects locally
• Continue development in your favorite IDE
• Review AI-generated code offline
• Archive project snapshots before major changes

PRIVACY
This extension does NOT collect any personal data. Authentication tokens are used in-memory only to communicate with the official Lovable API. No data is sent to third-party servers.

OPEN SOURCE
Source code: https://github.com/unchase/lovable-grab
```
